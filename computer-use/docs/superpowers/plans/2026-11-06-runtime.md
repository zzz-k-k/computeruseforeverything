# Computer Use Implementation Plan

**Goal:** Deliver local CLI and HTTP/MCP server for the approved tool design, then connect and use it.
**Architecture:** Shared Runtime with scoped frames and see_now sessions. CLI calls local authenticated server to preserve state. Swift implements macOS screen/input bridge. Fixed dsh-see-now provides visual pipeline.
**Tech Stack:** Node 24, official MCP SDK, Zod, Swift/Quartz/ScreenCaptureKit, FFmpeg.
**Spec:** ../../../../computer-use-docs/src/tool-docs/design.mjs and existing architecture pages.

## Global Constraints
Local deployment only. No PATH modification. Seven tools, see_now actions nested. Never reintroduce standalone watch. Keep document work intact. Initial deliverable targets this Mac, desktop permission failures must be explicit.

## Review Focus
Unauthorized requests cannot operate desktop. Invalid numbers/extra properties fail validation. Concurrent readers cannot steal results. Stopped captures do not restart silently. Image bytes and metadata survive each transport.

## Tasks
- [x] Native bridge: src/native/desktop.swift + macos.mjs, native tests. Expose displayLayout(), captureDisplay(id), postClick(point,right), postText(text), postKey(key), postScroll(point,dx,dy), permissions(). Real compiled JSON bridge. Test invalid commands and permissions safely.
- [x] Runtime: src/runtime.mjs and tools. createRuntime({stateDir,ffmpegPath,ffprobePath}) returns {list(),call(name,args,{sessionId,signal}),dispose()}. list entries {name,description,inputSchema}; call returns {result,images:[{mime_type,bytes}]}. Write failing validation/session tests, implement and pass. Vendor pinned code and apply documented patch.
- [x] Transports: src/transports/server.mjs exports startServer({runtime,token,port,host}) -> {url,close()}. HTTP GET /health, GET /v1/tools, POST /v1/tools/:name body {arguments,session_id}. Auth bearer token. MCP /mcp with SDK and stdio wrapper. CLI and server bins. Test real HTTP/MCP roundtrips using fixture runtime then real runtime.
- [x] Packaging and acceptance: executable local launchers, README and connection config. Real video_frame and see_now file start/watch/peek/status/stop through CLI, HTTP and MCP. Probe desktop permissions, use isolated test UI for controls if available. Record actual results and blockers. Run entire suite.

## Decisions
Existing design and user's instruction to implement authorize execution. New sibling directory isolates implementation from dirty docs. Native and transports delegated with disjoint files under dispatching-parallel-agents. All decisions default to this macOS host, optional upstream window/audio capabilities reported honestly.

## Acceptance record
18 automated tests and live MCP/HTTP/CLI media acceptance. Dedicated desktop fixture observed Unicode input, left/right click and scrollY=250. Later foreground switch caused unsent test text in Cursor; stopped injection and added strict fixture foreground guard. Fresh subagent review was unavailable due account quota; parent inspected integration. Native fixes include explicit event flags, inter-event delivery pacing, and natural-scroll direction conversion. Optional camera/OBS/Tk UI/audio not validated on this host.
